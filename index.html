🎯 Project Objective

This project demonstrates automated deployment of a web application from GitHub to Apache Tomcat using Jenkins. It includes source code checkout, HTML validation, backup management, deployment and HTTP testing.

CI/CD Pipeline

Six stages of automated application delivery.

⚡ Pipeline Execution Flow

🐙 GitHub Checkout
🔍 HTML Validation
📦 Build Backup
💾 Deployment Backup
🚀 Tomcat Deployment
✅ Application Testing

🔄 Automated Workflow

1. Developer updates index.html.
2. Changes are pushed to GitHub main branch.
3. Jenkins detects changes using SCM polling.
4. Jenkins validates the HTML file.
5. Build and deployment backups are created.
6. Latest application is deployed to Tomcat.
7. HTTP response is tested.
